UBC Tours — Schedule Updater

Upload the monthly schedule PDFs and download the finished website files. No coding, no Claude.

Step 1

Add the schedule PDFs

Select all the months you want live (e.g. June, July, August). Each person gets one calendar covering every month, so include them all together.

    Step 2

    Check the schedule

    Spot-check anyone (type a name to see their shifts):

    Step 3

    Download & publish

    This gives you a .zip with the updated index.html and cal folder — the same two things you upload to GitHub.

    Last step
    1. Unzip the downloaded file — you'll get index.html and a cal folder.
    2. Go to your repo: github.com/rinahatakeyama3-coder/UBC_Tours
    3. Click Add file → Upload files, drag in both index.html and the cal folder, then Commit changes.
    4. Wait ~2 minutes, then hard-refresh the live site (Cmd+Shift+R). Everyone's subscribed calendars update on their own.

    Tip: open this page from your live site (the github.io link) so it can use your current site as the starting template.
